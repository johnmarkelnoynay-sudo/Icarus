# Prompt Library

This directory contains reusable prompts and project specifications for building the GitHub developer portfolio.

## Files

- `portfolio-brief.md` — Complete portfolio requirements and specifications
- `prompt-index.md` — Quick reference index of all prompts

## Usage

Each prompt file contains a complete specification that can be reused for:
- Generating README files
- Creating project documentation
- Setting up repository structures
- Maintaining consistent portfolio messaging
